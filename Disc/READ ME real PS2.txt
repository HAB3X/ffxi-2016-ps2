FFXI 2016 PS2 EDITION: REAL PS2
Fan Project by Habex
===============================

Only for a real PS2 with a hard drive. Using PCSX2? You don't need this page.


YOU NEED

  - A thick (original) PS2 that can boot burned discs (modchip or FreeMcBoot)
  - The Sony network adapter and a hard drive (the official 40 GB is safest). Slim PS2s have no drive bay.
  - A network cable to the computer running the Server App (or the same router)
  - The patched disc (Server App > Tools > Game disc > Patch My Disc, saved in Disc/Patched ISO)
  - A blank single-layer DVD-R and a DVD burner


1  FORMAT THE HARD DRIVE ON THE PS2

  The drive must be formatted by the console. The Server App's "Make Hard Drive" is for PCSX2 only.

  Use wLaunchELF (free PS2 file manager): open its HDD manager > menu > Format > confirm.
  Sony's HDD Utility disc also works. hdl-dump can't format a blank drive, so don't use it.

  Formatting erases the whole drive.


2  BURN THE DISC

  Burn the .iso as a disc image, not as a file on a data disc:
    Windows   right-click the .iso > Burn disc image
    Mac       Finder: right-click > Burn Disc Image
    Linux     Brasero or K3b, or: growisofs -dvd-compat -Z /dev/sr0="FFXI 2016 (Patched).iso"
  Burn slowly (4x) if you can. If the PS2 can't read it, try another DVD-R brand.


3  INSTALL

  Plug in the adapter, drive and cable, and boot the burned disc. The installer runs by itself and takes a while.
  When it's done, the game opens the sign in page. After that the disc goes straight to sign in.
  Hold L1 while the disc starts to install again.


4  SIGN IN

  Start the Server App, click Start and create a profile (Players page).
  On the PS2's sign in page fill in POL-ID, Password, ServerIP and ServerPort. The Invite page tells you what to type:
    Same router      the computer's home network address
    Direct cable     set the computer's Ethernet to 192.168.137.1 / 255.255.255.0, type 192.168.137.1
    Over internet    your hostname, with the ports forwarded
  Choose OK and create your character.

  If it won't connect with the server working, set up the console's network with Sony's Network Adapter software and try again.


IF SOMETHING GOES WRONG

  Disc not read                        Burn again slower, or try another DVD-R brand.
  Installer says it needs a drive      The drive isn't formatted (step 1).
  FFXI-3100 / FFXI-3101 at sign in     Check the address and ports (READ ME Server App.txt, Connection trouble).
                                       Still failing? Report it with your console model.
  Crash when opening a menu            Report it with your console model.

Not everything here could be tested on real hardware (slim models, drive sizes, burn speeds).
If something's different on your console, tell us on the GitHub Issues page.
