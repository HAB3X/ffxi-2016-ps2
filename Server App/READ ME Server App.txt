FFXI 2016 SERVER APP
Fan Project by Habex
===========================================

OPEN IT
  Mac      double click  FFXI Server
           First time: if the Mac says it cannot check the app, right click it > Open > Open.
           If the Mac asks whether FFXI Server may use the Downloads folder, click Allow.
           If the Mac asks whether Python or xi_map may accept incoming connections, click Allow.
  Windows  double click  FFXI Server (Windows).bat
           Windows asks once whether the programs may use the network: click Allow.
  Linux    double click  FFXI Server (Linux).sh   (or run it in a terminal)
           The first run also adds "FFXI Server" to your applications menu.

FIRST TIME ON A NEW COMPUTER
  If something is missing, the Server page shows a yellow line with "Run Setup". Click it, follow the
  window that opens, then click "Check again".
    Mac (Apple M series): a few minutes.
    Intel Mac, Windows, Linux: also builds the game server programs (20 to 90 minutes, once).

PAGES (left side)
  Server       Start / Stop, and "Working" or "Not working" with the fix.
               The Local address, Internet address and Port to give your players (copy; "hide" covers the
               addresses when you share your screen, and the app remembers the choice).
               Online now: who is playing, zone, job, role. Select a player and use "Actions for the selected
               player" (or right click).
               World chat: what players say, live. Type and press Enter to send a message to everyone.
                 Type / for the command list (it shows as you type; arrow keys and Tab or Enter to pick),
                 @ for a player name. Examples:  /tp Habex lower jeuno   /give @Habex hi-potion 3
  Profiles     Create Profile (POL-ID is the profile name). Every profile with its characters.
               Right click: change password, ban or unban, and the player actions.
  Connect      What to type on the PS2 for Local, Direct cable and Over the internet. Hostname: type one, or let
               the app keep it up to date (DuckDNS, No-IP, Dynu or any provider's update link). The 4 ports to
               forward on your router (TCP 54001, UDP 54240, TCP 54242, TCP 54460), "Open ports for me"
               (asks the router, UPnP) and "Test my ports".
  World        The name players see, a welcome message sent to each player who logs in, the experience, gil,
               drop and skill-up rates (they apply after the next server start), and backups of all players
               and characters (Back up now, Restore from a backup).
               Auction house tab: "Stock the auction house" puts ordinary items on sale (pick the kinds, how
               many listings of each, and the price as a percentage of the normal price; it can refill by
               itself every hour, 6 hours or day while this window is open). The seller is a server character
               called Server_AH. "Remove the server's listings" takes back only those; players' listings are
               never touched. The server (database) must be on.
               Modes tab: plain on/off switches for small gameplay changes (a gentler experience curve for
               levels 53 to 76, fair gathering points, an escape hole in Castle Oztroja). All are off until
               you switch them on, and each applies after the next server start (the game reads them only
               when it starts). They are from LoxleyXI's open source modules (Server/lsb/modules/README_MODES.md).
               The experience switch changes the database, so the server must be on to change it. The Oztroja
               hole could not be tested with the PS2 game.
  Roles        Make roles (for example Head Admin, Moderator) and tick which in game "!" commands they
               may use. Right click a player > Promote > role. Players without a role cannot use any
               "!" GM command.
  Chat rules   Word filter (lists, and what happens: replace with XXXX, warn, tell moderators, kick,
               kick then ban after strikes, jail), spam limit, scheduled messages, chat history
               (search a player, export to a file) and the filter log.
  Game disc    Patch My Disc: pick your original disc file (Disc/Original Disc); the patched disc goes
               to Disc/Patched ISO. Make Hard Drive: makes the formatted PS2 hard drive for PCSX2.
               Test in PCSX2: starts PCSX2 with the patched disc (PCSX2 -batch -- "disc"). It looks for
               PCSX2 in the usual places; if it cannot find it, pick it once with "Choose PCSX2..." (it is
               remembered). It will not start if the patched disc is missing or PCSX2 is already open. The
               hard drive is chosen once in PCSX2's own settings, as the page explains.
               "Open the real PS2 guide" opens Disc/READ ME real PS2.txt (a real console with a hard drive).
  Maintenance  General: backups, Discord messages, health. Debug: the PS2 login part's log in readable
               form (All, Diagnostics, Events, Zone changes, Errors), the last 300 lines, refreshed every
               two seconds while open, with a Copy button.

WHERE THINGS ARE KEPT
  Server/data   made at the first start: the database, profiles, roles, chat rules, chat history, logs.
                It is private to this computer. Server/data/players.txt holds the profile passwords.
                When you give the release folder to someone else, leave Server/data out.

UPDATES
  The app checks GitHub now and then for newer versions of the app and server scripts. When there is one, a bar at the top asks
  whether to update now. "Always update automatically" (also the "Auto update" switch at the bottom left) downloads updates in the
  background; close and open the app again to use them. Only the app, scripts and read me files are updated. Your players, settings,
  database and discs are never touched, and a new disc or patch still comes from the Releases page.
